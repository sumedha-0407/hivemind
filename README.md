# HIVEMIND

### AI-Powered Student Productivity & Academic Management Platform

## Overview
HIVEMIND is a student productivity and academic management platform designed to centralize essential academic tools into a single system. The goal is to improve organization, communication, and efficiency within a college environment by integrating attendance tracking, academic resources, student records, and task management.

## Problem Statement
- Attendance tracking is unclear or manually maintained
- Study materials are scattered across different platforms
- Assignment deadlines and academic notifications are easily missed
- Student documents are stored in multiple places without proper organization
- Communication between students and faculty is inefficient

## Key Features
1. Smart Attendance Tracker
2. ML-Based Attendance Risk Prediction
3. Leave Application Portal
4. Study Material Cloud Storage
5. Student DigiLocker
6. Secure Student Profile System
7. Academic Communication Chatbox
8. Assignment Deadline Manager
9. Digital Notice Board

## Tech Stack
- **Backend:** Django 6.0.3
- **Frontend:** React (coming soon)
- **Database:** SQLite (development) / PostgreSQL (production)
- **Language:** Python 3.14.3
